TXC station batch cards OPTIONAL

These cards are optional. The default at every station is plain rapid scanning: pass each finished sheet under the scanner. The screen keeps a running count. Use a batch card only if you want every sheet in a cart to share one completion time. Print this page, cut out a card, and tape it at the station. Nothing on this page is required to scan.

How to use (optional): Scan this card to start a batch → scan each finished sheet → scan this card again to close. The screen shows BATCH OPEN and a count. An open batch auto-closes after 30 minutes idle. Press / Trim should still scan each piece after trim, even if a card is posted there.
